PR Reviewer Presets

The extension asks reviewers through the GitHub API, so it needs a token. The token stays in this browser and is only sent to api.github.com.

With the GitHub CLI, copy your current token. It carries every scope your CLI login has.

gh auth token | pbcopy

Or create a narrower one: a classic token with the repo scope, or a fine-grained token with read and write access to pull requests.
